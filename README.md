# チェッカーボード 色錯視 キャンバス

アデルソンのチェッカー錯視・ホワイト錯視・ハーマン格子など有名な色の錯視パターンをCanvasで自動生成するインタラクティブツール。

## 機能
- 3種類の錯視パターン切替:
  1. アデルソンのチェッカー錯視（影のかかったチェス盤上の同色マス）
  2. ホワイト錯視（同じ灰色バーが背景によって違う明度に見える）
  3. ハーマン格子（白線の交差点に灰色の幻影）
- 「答えを見る」ボタン: 同色マスを接続線・マーカーで強調
- 各錯視の仕組み解説テキスト
- コントラスト調整スライダー
- 実際のRGB値の表示

## 技術
- Vanilla JS + Tailwind CSS CDN
- Canvas 2D API による錯視パターン自動生成
- localStorage 不使用（状態は単純なUI変数で管理）
